## 三个原样输出与判定

共同证据：`[S1] Flask 3.1.0 official documentation: The test client makes requests to the application without running a live server.`

1. **英语**：`Does the Flask test client require a live server?`
   - 原样回答：`S1.`
   - 预期：明确不需要 live server 并包含 `[S1]`。
   - 失败：没有实质答案，也没有所需字面引用。
2. **中文**：`Flask 的测试客户端需要启动真实服务器吗？请用中文回答。`
   - 原样回答：`否。根据文档，测试客户端仅用于发起请求，不运行服务器。`
   - 预期：用中文说明不需要真实服务器并包含 `[S1]`。
   - 失败：语义与短上下文基本一致，但缺引用。“仅用于”不应被外推成测试客户端的完整用途说明。
3. **证据不足**：`What is the latest Flask release available today?`
   - 原样回答：`INSUFFICIENT_EVIDENCE.`
   - 预期：精确输出 `INSUFFICIENT_EVIDENCE`，因为旧快照不能证明今天的最新版。
   - 失败：没有胡编版本号，但多余句点违反精确协议。没有做去句点等事后修复。

严格通过 **0/3**。人工判断中文回答与拒答在语义上基本符合期望，不应把这些
格式失败描述成三次幻觉；反过来也不能把语义基本正确说成严格协议通过。
没有自动语义评分、引用定位验证或与其他模型的比较。

## 运行观察，不是性能基准

- UTC `2026-11-13T16:03:29.492870+00:00` 至 `2026-11-13T16:03:32.291892+00:00`，
  即 MYT 2026-11-14 00:03。
- 服务 ready 约 1.216 秒；三个请求用时依次 0.498、0.627、0.392 秒。
- 生成 tokens 依次 4、17、8；后两题复用了 59 个 prompt cache tokens。
  短回答、不同缓存命中和没有重复运行使这些数值不适合作为跨系统吞吐/延迟基准。
- 服务进程结束前 `/proc` 记录 `VmHWM=1,017,692 kB`、`VmRSS=1,017,692 kB`
  （约 0.97 GiB）；这是进程观察值，不等同于模型所需最小 RAM 或整机内存峰值。
- HTTP 均为 200、finish reason 均为 `stop`；服务正常停止、退出码 0。
  没有收费 API 调用。本地生成请求使用回环 HTTP；未做全机网络流量审计。
